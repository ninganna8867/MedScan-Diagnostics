\# MedScan Diagnostics – Research Notes



\## Reference 1: ResNet Transfer Learning

Paper: Efficacy of Transfer Learning-based ResNet models in Chest X-ray image classification (2022)



Key findings:

\- Compares ResNet-18, ResNet-34, ResNet-50 and deeper models.

\- Uses transfer learning for chest X-ray classification.

\- Shows that ResNet architectures can learn useful image features.

\- Supports investigating ResNet-18 as our baseline model.



\## Reference 2: COVID-19 Classification and Grad-CAM

Paper: COVID-19 Detection and Disease Progression Visualization (2020)



Key findings:

\- Uses transfer learning for chest X-ray classification.

\- Studies COVID-19, pneumonia and normal cases.

\- Uses Grad-CAM to highlight important image regions.

\- Supports adding explainability to our project.



\## Reference 3: Leakage-Aware Chest X-ray Classification

Repository: Reproducible Chest X-ray Pneumonia Classification Study



Key findings:

\- Emphasizes patient-level data splitting.

\- Discusses data leakage and model generalization.

\- Highlights the importance of reliable testing.

\- Supports careful dataset preparation.



\## Research Conclusion



Our project will begin with ResNet-18 transfer learning.

We will use Grad-CAM for visual explanations.

We will evaluate the model using AUC, sensitivity,

specificity and COVID-19 false-negative rate.



The model is for educational purposes only.

It is not intended for medical diagnosis.
