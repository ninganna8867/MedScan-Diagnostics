\# MedScan Diagnostics 🩺



\## Project Overview

An AI/ML project that classifies chest X-ray images into three categories using Deep Learning.



\## Classification Categories

\- Normal

\- Pneumonia

\- COVID-19



\## Model Architecture

ResNet-18 using Transfer Learning.



\## Technologies Used

\- Python 3.11

\- PyTorch

\- Torchvision

\- NumPy

\- Pandas

\- Matplotlib

\- Scikit-learn

\- Grad-CAM

\- Gradio



\## Project Objectives

1\. Develop a chest X-ray classification model.

2\. Predict probabilities for all three classes.

3\. Evaluate model performance using AUC.

4\. Generate Grad-CAM heatmaps.

5\. Build an interactive Gradio application.



\## Disclaimer

This project is for educational and research purposes only. It is not a substitute for professional medical diagnosis.
